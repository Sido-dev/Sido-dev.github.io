# Sudhanshu Portfolio

Extract the ZIP and open index.html in your browser.

Alternatively, run `python -m http.server 8000` in this folder and visit http://localhost:8000.

Edit index.html for content, style.css for styling, and app.js for interactions. No installation or build is required. External fonts require internet access.

Upload index.html, style.css and app.js together to any static website host.
